## 사용 방법

1. 위의 설치 파일을 다운로드한 뒤 실행합니다.
2. 설치를 마치고 바탕화면의 RoomPay Manager를 엽니다.
3. 관리자가 발급한 기존 아이디와 비밀번호로 로그인합니다.

인터넷 연결과 사용 권한이 있는 계정이 필요합니다. Node.js나 별도 개발 서버는 필요하지 않습니다.

코드 서명이 없는 파일이므로 Windows에서 게시자 확인 메시지가 나올 수 있습니다. 다운로드 출처가 이 저장소인지 확인하세요.

자동 업데이트는 제공하지 않습니다. 새 버전은 최신 버전 다운로드 페이지에서 확인하세요.
